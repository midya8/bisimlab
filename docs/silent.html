Silence can hide
a choice.

Strong bisimulation matches every original step. Weak bisimulation permits silent detours. Branching bisimulation also checks the choice available just before the matched step.

Divergence-insensitive, unrooted semantics. A silent loop can be equivalent to deadlock. The separate cycle witnesses below show why this is not a termination, fairness or liveness guarantee.

1. Choose what to hide

Only labels explicitly listed in silent are hidden. Multiple hidden labels become the same unobservable action. A literal label named tau is otherwise visible. Strong mode keeps every original label visible.

2. Keep the three answers separate

Possible infinite internal activity

A reachable silent cycle witnesses possible divergence. It does not change the divergence-insensitive equivalence answers. No divergence-preserving semantics is computed.

3. Watch every failed response

Each reachable silent endpoint has one canonical shortest path, tied by input edge IDs. Response rows enumerate endpoint/central-edge combinations, not infinitely many paths. Branching requires the before-step and target pairs shown in each row; a path's intermediate states are not claimed to satisfy a particular refinement round. Final equivalence obeys the published stuttering property.

4. Read the supplied graph
Dashed edges are hidden. Every edge label includes its input edge ID. Node qN uses state index N; full supplied names are in the cards and tables. Names are not observations or propositions.


5. Replay without the generator
The Python verifier independently enumerates simple silent paths, reconstructs all records using sets, and checks every synchronous round. Tests additionally enumerate candidate bisimulation relations rather than refining them. Optional unmodified mCRL2 ltscompare checks the final equivalence answers.
