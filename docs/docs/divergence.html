04 / WHAT THIS ESTABLISHES
Same choices, including the silent forever.
The coarsest valid partition contains every other valid partition. Every same-block pair is equivalent. The finite atlas checks this containment explicitly. A reachable nonempty internal cycle witnesses an infinite internal path; a terminating internal path does not.
The first control reconstructs Luttik2020 Example3/Figure1. States s and t both have possible infinite silence and are divergence-insensitive branching equivalent. Only s can diverge while preserving the block where action a is available. Merely adding one global "can diverge" flag is too weak.
This is classical explicit-divergence semantics, not a new equivalence or scalable algorithm. It is distinct from the technical term "divergence-sensitive branching" and from rooted, stability-respecting, probabilistic or fairness semantics. A downloaded report is replayable evidence, not a signature or formal proof.
