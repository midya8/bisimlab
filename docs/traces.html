Don't sample a few paths. Build the complete reachable product of two agents' possible state sets, then inspect why a finite action word is possible on only one side.

Finite trace languages, not branching equivalence. All labels visible; no model, API or depth cutoff.

1. Select a state pair

A word is possible if its reachable state set is nonempty. Every original state allows the empty word. No accepting states or final-state labels are inferred from names.

2. Read the language verdict

Traversal continues after the first mismatch. Every reachable successor is included, even when both sides have already reached the empty set.

3. Inspect a reachable subset pair

Each product node stands for two state sets after the same word. Same-labelled nondeterministic transitions are unioned, not counted. The same subset pair is stored once.

Node and provenance

Every action successor

4. Replay the breadth-first layers

Root first, then action order from the input. A new node gets its ID, parent and action on first discovery. This supplies a shortest word to each reachable node, not a list of every word.

“Mismatch frontier” means all reachable possibility-mismatch nodes, not an antichain, a minimal set or every distinguishing word. A mismatch may lead to another mismatch or to the both-empty sink.

5. Follow the shortest counterexample

The first mismatch in canonical BFS order has minimum depth. Ties follow the input action order. Every path prefix retains its left and right reachable subsets.

A nonempty mismatch set proves different finite trace languages. No mismatches in the closed reachable product proves finite trace equality. Equal traces do not establish strong bisimulation of the original states.

6. Check the complete report

The separate native checker precomputes explicit-set transitions for every original subset, independently rebuilds reachability and checks every node, successor, layer, provenance edge, mismatch and shortest witness. It never calls the generator.
