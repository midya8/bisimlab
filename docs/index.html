Original bounded implementation. No model, API, probability or hidden execution.

1. Choose a protocol

State names are identifiers, not observations. Every action is visible, including an action named tau. No silent steps, rewards, propositions, acceptance states or fairness.

2. Inspect the transition graph

Read each directed edge as source - action - target. Parallel choices with the same label remain separate transitions.

3. Watch the relation shrink

Round zero relates every ordered pair. A pair survives only when every step on either side has a same-action answer whose targets survived the previous round. The final unchanged round certifies stability.

4. Explain a state pair

Modal distinguishing witness

Exact finite-trace comparison

Modal depth is the number of nested action observations. A first-removal round gives minimum distinguishing depth for this finite visible-action logic. Formula size and negation count are not minimized. A trace witness is a shortest finite sequence, not a modal formula.

5. Replay every modal node

F0 is true. Each other node uses only earlier node IDs. These shared DAG references avoid expanding repeated subformulas. “Holds” is computed over every original state.

6. Check the whole report

The native verifier independently reconstructs partition-signature rounds, checks all attack/match records, evaluates every modal node and compares trace languages with explicit reachable subsets. It does not call the generator. It is an executable audit, not a formal proof or signature.

Scope and sources
One to six states, zero to three labels, at most eighteen unique edges. All ordered pairs, including unreachable states. Strong bisimulation is a branching-behavior equivalence, not equality of policies or a guarantee about a deployed AI system. Protocols are small hand-written models, not extracted programs.
Complete finite-trace comparison uses BFS over pairs of reachable state subsets. No trace-depth cutoff. It may explore exponentially many subset pairs, so the input cap is deliberate. This is an educational implementation of established ideas, not a new or scalable solver.
